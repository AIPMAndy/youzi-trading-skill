## 简介

这是一个基于《23位著名游资心法解读版》和实战经验总结的A股超短线交易系统Skill，适用于Hermes Agent、OpenClaw、Claude Code等AI Agent平台。

**核心理念**：
- 超短交易 = 群体博弈 + 情绪周期
- 别人贪婪时我更贪婪，别人恐慌时我更恐慌
- 弱市不做，强市重仓
- 只做龙头，只做主升浪

## 功能特性

### 九大核心模块
1. **选股**：如何找到强势股（龙头识别三要素）
2. **仓位**：根据市场强弱动态控制（强势60-80%，弱势0-20%）
3. **回撤**：控制回撤的三大关键习惯
4. **情绪**：理解情绪周期，猜准市场节奏
5. **止损**：亏损单不过夜（短线第一原则）
6. **概率**：做概率的信徒，每一个决策都拥抱大概率
7. **复盘**：在系统复盘中执行可交易计划
8. **系统**：构建可持续、可复制的交易系统
9. **执行力**：坚决执行系统内的操作，不主观，不侥幸

### 三大实战战法
1. **龙头主升战法**（最适合散户）：只做龙头，只做主升浪，只做惯性
2. **打板战法**（追求确定性）：涨停板上买入，第二天高开卖出
3. **超跌反弹战法**（弱市专用）：等待极度超跌后的反弹信号

### 择时策略
- **强势市场**：重仓进攻（60-80%）
- **震荡市场**：中仓观望（30-50%）
- **弱势市场**：空仓休息（0-20%）

## 使用场景

### 1. 持仓诊断
```
用户：我的持仓10只股票，9只都在亏损

AI：基于游资心法诊断：
1. 是否在弱市做短线？（择时问题）
2. 是否持有跟风股？（选股问题）
3. 是否满仓操作？（仓位问题）

建议：
- 清理跟风股，只留龙头
- 降低仓位到30-50%
- 弱市空仓休息
```

### 2. 选股建议
```
用户：现在应该买什么股票？

AI：基于游资心法：
1. 先看市场：当前是强势/震荡/弱势？
2. 再看板块：哪些板块在轮动？
3. 最后看个股：哪些是龙头？

龙头识别三要素：
- 以三连板启动
- 能先于大盘止跌
- 对板块有拉升效果
```

### 3. 亏损复盘
```
用户：一直亏钱，不知道怎么办

AI：基于游资心法复盘：
常见错误：
1. 追涨杀跌，频繁交易
2. 抄底思维，越跌越买
3. 被套不止损，补仓摊成本
4. 做杂毛，不专注龙头
5. 满仓操作，不控制仓位

纠正方案：
- 短线第一原则：亏损单不过夜
- 克服成本障碍，忘记成本
- 只做龙头，跟风股不看、不买、不研究
```

## 风险提示

### 游资交易的风险
1. **高波动风险**：短线追涨，一旦判断错误可能面临大幅回撤
2. **情绪失控风险**：频繁交易容易被情绪控制
3. **系统性风险**：弱市做短线，成功概率极低

### 适合人群
- ✅ 有一定交易经验的投资者
- ✅ 能够控制情绪的投资者
- ✅ 有时间盯盘复盘的投资者
- ❌ 新手小白（建议先学习，小资金练手）
- ❌ 上班族（没时间盯盘）
- ❌ 风险承受能力低的投资者
